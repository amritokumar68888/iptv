# এই file টা save করলেই গ্রাহকের অ্যাপ পরেরবার খোলার সময় নতুন list পাবে -
# নতুন APK build করার দরকার নেই.
#
# Format:
#   - exact IP        ->  103.7.4.12      (শুধু ওই একটা IP)
#   - CIDR            ->  103.7.4.0/24    (103.7.4.0 - 103.7.4.255, সব allowed)
#   - CIDR ছোট হলে    ->  103.7.0.0/16    (103.7.0.0 - 103.7.255.255)
#   - prefix wildcard ->  103.7.4.*       (উপরের /24-এর সমান)
#   - শেষে dot        ->  103.7.4.        (এও /24-এর সমান)
#   - '#' দিয়ে comment (এই লাইনগুলো পড়া হয় না)
#
# 💡 /24 দিলে ওই নেটওয়ার্কের সব IP অটোমেটিক allowed - এক একটা করে
#    লিখতে হবে না. সংখ্যা: /24 = 256টা, /16 = 65,536টা, /8 = 16.7 মিলিয়ন.
#
# ⚠️ "103.7.4.0" লিখলে শুধু ওই একটা IP allowed - পুরো range পেতে
#    "/24" দিন (এটা behavior, bug নয়).
